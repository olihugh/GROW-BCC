## GROW Bulk Centile Calculator in R ##

The global version of the Customised Centile Calculator allows calculation of centiles for birthweight and ultrasound-derived estimated fetal weight, 
for 120 ethnic, country of origin and region coefficients. It is based on data from over 4 million pregnancies submitted from 33 countries. 

This directory contains two files:
1. The BCC R User Guide - we recommend you read this before proceeding to using the BCC
2. Template, this is the template R script to calculate customised centiles.

Before being able to use the bulk centile calculator, you'll need an API key, which can be acquired using our contact form:
https://contact.perinatal.org.uk/ 

Please email any feedback or questions to data@perinatal.org.uk
